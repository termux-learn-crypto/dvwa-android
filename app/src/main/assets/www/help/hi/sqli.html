Help - SQL Injection

परिचय (About)

एक SQL Injection अटैक में क्लाइंट से एप्लीकेशन के इनपुट डेटा के माध्यम से SQL query को डालना या "inject" करना शामिल होता है। एक सफल SQL Injection एक्सप्लॉइट डेटाबेस से संवेदनशील डेटा पढ़ सकता है, डेटाबेस डेटा को संशोधित कर सकता है (insert/update/delete), डेटाबेस पर एडमिनिस्ट्रेशन ऑपरेशन निष्पादित कर सकता है (जैसे DBMS को बंद करना), DBMS फाइल सिस्टम पर मौजूद किसी दी गई फाइल की सामग्री को पुनर्प्राप्त कर सकता है (load_file) और कुछ मामलों में ऑपरेटिंग सिस्टम को कमांड जारी कर सकता है।

SQL Injection अटैक एक प्रकार का injection अटैक है, जिसमें पूर्वनिर्धारित SQL commands के निष्पादन को प्रभावित करने के लिए डेटा-प्लेन इनपुट में SQL commands को inject किया जाता है।

इस अटैक को "SQLi" भी कहा जा सकता है।



उद्देश्य (Objective)

डेटाबेस में 5 users हैं, जिनकी id 1 से 5 तक है। आपका मिशन... SQLi के जरिए उनके पासवर्ड चुराना है।



Low Level

SQL query कच्चे (RAW) इनपुट का उपयोग करती है जो सीधे हमलावर के नियंत्रण में होता है। उन्हें केवल query से बाहर निकलना (escape करना) होता है और फिर वे अपनी इच्छानुसार कोई भी SQL query निष्पादित करने में सक्षम होते हैं।

Spoiler (जवाब): ?id=a' UNION SELECT "text1","text2";-- -&Submit=Submit.

Medium Level

Medium level SQL injection सुरक्षा के एक रूप का उपयोग करता है, जिसमें "mysql_real_escape_string()" फंक्शन होता है। हालाँकि SQL query में पैरामीटर के चारों ओर कोट्स (quotes) न होने के कारण, यह query को बदले जाने से पूरी तरह सुरक्षित नहीं करेगा।

टेक्स्ट बॉक्स को एक पूर्वनिर्धारित ड्रॉपडाउन सूची से बदल दिया गया है और यह फॉर्म सबमिट करने के लिए POST का उपयोग करता है।

Spoiler (जवाब): ?id=a UNION SELECT 1,2;-- -&Submit=Submit.

High Level

यह Low level के बहुत समान है, हालांकि इस बार हमलावर एक अलग तरीके से वैल्यू इनपुट कर रहा है। इनपुट वैल्यू को सीधे GET अनुरोध के बजाय, दूसरे पेज का उपयोग करके सेशन वेरिएबल्स के माध्यम से vulnerbale query में स्थानांतरित किया जा रहा है।

Spoiler (जवाब): ID: a' UNION SELECT "text1","text2";-- -&Submit=Submit.

Impossible Level

queries अब पैरामीट्रिज़्ड queries हैं (डायनेमिक होने के बजाय)। इसका मतलब है कि query को डेवलपर द्वारा परिभाषित किया गया है, और यह अंतर बताती है कि कौन से हिस्से कोड हैं, और बाकी डेटा है।
