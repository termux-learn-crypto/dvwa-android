Help - Authorisation Bypass

परिचय (About)

जब डेवलपर्स को जटिल प्रणालियों (complex systems) में authorisation matrices बनानी होती हैं, तो उनके लिए हर जगह सही जाँच (checks) जोड़ना भूल जाना बहुत आसान होता है, खासकर उन जगहों पर जो ब्राउज़र के माध्यम से सीधे सुलभ (accessible) नहीं होती हैं, उदाहरण के लिए API calls।

एक टेस्टर के रूप में, आपको सिस्टम द्वारा की जाने वाली हर call को देखना होगा और फिर यह सुनिश्चित करने के लिए कि जाँच सही तरीके से की जा रही है, यूजर के हर level का उपयोग करके इसका परीक्षण करना होगा। यह अक्सर एक लंबा और उबाऊ काम हो सकता है, खासकर एक बड़े matrix के साथ जिसमें कई अलग-अलग user types होते हैं, लेकिन यह परीक्षण करना बहुत महत्वपूर्ण है क्योंकि एक भी छूटी हुई जाँच के कारण किसी हमलावर (attacker) को गोपनीय डेटा या functions तक पहुंच मिल सकती है।



उद्देश्य (Objective)

आपका लक्ष्य यह पता लगाने के लिए सभी चार security levels पर इस user management system का परीक्षण करना है कि authorisation की जाँच कहाँ छूटी है।

यह सिस्टम केवल admin user द्वारा एक्सेस किए जाने के लिए डिज़ाइन किया गया है, इसलिए admin के रूप में लॉग इन होने पर की जाने वाली सभी calls को देखें, और फिर एक अलग user के रूप में लॉग इन करके उन्हें पुन: उत्पन्न (reproduce) करने का प्रयास करें।

यदि आपको दूसरे user की आवश्यकता है, तो आप gordonb / abc123 का उपयोग कर सकते हैं।


Low Level

गैर-admin users के पास 'Authorisation Bypass' मेनू विकल्प नहीं होता है।

Spoiler (जवाब): Try browsing directly to /vulnerabilities/authbypass/.


Medium Level

डेलवपर ने पेज के लिए HTML तक पहुंच को लॉक कर दिया है, लेकिन देखें कि admin के रूप में लॉग इन होने पर पेज कैसे पॉप्युलेट (populate) होता है।

Spoiler (जवाब): Try browsing directly to /vulnerabilities/authbypass/get_user_data.php to access the API which returns the user data for the page.


High Level

HTML पेज और डेटा पुनः प्राप्त (retrieve) करने वाली API दोनों को लॉक कर दिया गया है, लेकिन डेटा अपडेट करने का क्या? आपको यह सुनिश्चित करना होगा कि आप साइट पर हर call का परीक्षण करें।

Spoiler (जवाब): GET calls to retrieve data have been locked down but the POST to update the data has been missed, can you figure out how to call it?

Spoiler (जवाब): This is one way to do it:

fetch('change_user_details.php', {
method: 'POST',
headers: {
'Accept': 'application/json',
'Content-Type': 'application/json'
},
body: JSON.stringify({ 'id':1, "first_name": "Harry", "surname": "Hacker" })
}
)
.then((response) => response.json())
.then((data) => console.log(data));

Impossible Level

आशा है कि इस level पर सभी functions डेटा तक पहुंच की अनुमति देने से पहले authorisation की सही जाँच करते हैं।

हालाँकि पेज पर कुछ ऐसे मुद्दे हो सकते हैं जो authorisation से संबंधित नहीं हैं, इसलिए इसे पूरी तरह से सुरक्षित मानकर नजरअंदाज न करें।
