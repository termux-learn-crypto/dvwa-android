Help - Client Side JavaScript

परिचय (About)

इस सेक्शन के हमले आपको यह सीखने में मदद करने के लिए डिज़ाइन किए गए हैं कि ब्राउज़र में JavaScript का उपयोग कैसे किया जाता है और इसे कैसे हेरफेर (manipulate) किया जा सकता है। इन हमलों को केवल नेटवर्क ट्रैफ़िक का विश्लेषण करके भी अंजाम दिया जा सकता है, लेकिन बात वह नहीं है और इससे काम शायद बहुत ज़्यादा मुश्किल भी हो जाता।

उद्देश्य (Objective)

लेवल जीतने के लिए बस "success" फ़्रेज़ सबमिट करें। ज़ाहिर है, यह इतना आसान नहीं है, हर लेवल में अलग-अलग सुरक्षा तंत्र (protection mechanisms) लागू किए गए हैं, पेजों में शामिल JavaScript का विश्लेषण करना होगा और फिर सुरक्षा को बायपास करने के लिए इसमें फेरबदल करना होगा।

Low Level

सारी JavaScript पेज में ही शामिल है। सोर्स को पढ़ें और पता लगाएँ कि फ़्रेज़ से मैच करने के लिए ज़रूरी token जनरेट करने के लिए किस फ़ंक्शन का उपयोग किया जा रहा है और फिर मैन्युअली फ़ंक्शन को कॉल करें।

Spoiler (जवाब): Change the phrase to success and then use the function generate_token() to update the token.


Medium Level

JavaScript को उसकी अपनी फ़ाइल में अलग कर दिया गया है और फिर उसे मिनिमाइज़ कर दिया गया है। आपको शामिल की गई फ़ाइल के लिए सोर्स देखना होगा और फिर पता लगाना होगा कि यह क्या कर रही है। Firefox और Chrome दोनों में एक Pretty Print फ़ीचर होता है जो कम्प्रेशन को उलटने और कोड को पढ़ने योग्य तरीके से दिखाने की कोशिश करता है।

High Level

JavaScript को कम से कम एक इंजन द्वारा ऑबफ़uscate (अस्पष्ट) किया गया है। यह पता लगाने के लिए कि क्या उपयोगी है, क्या कचरा है और मिशन को पूरा करने के लिए क्या ज़रूरी है, आपको कोड को स्टेप-बाय-स्टेप देखना होगा।

Impossible Level

आप कभी भी यूज़र पर भरोसा नहीं कर सकते और आपको यह मानकर चलना होगा कि यूज़र को भेजा जाने वाला कोई भी कोड बदला या बायपास किया जा सकता है और इसलिए कोई impossible level नहीं है।
