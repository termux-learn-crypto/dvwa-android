Help - Cross Site Scripting (Reflected)

Parichay (About)

"Cross-Site Scripting (XSS)" attacks ek tarah ki injection problem hain, jisme malicious scripts ko aisi websites mein inject kiya jata hai jo normally benign aur trusted hoti hain. XSS attacks tab hote hain jab attacker web application ka use karke malicious code (generally browser side script ke roop mein) kisi doosre end user ko bhejta hai. Aise flaws bohot widespread hain aur wahan milte hain jahan web application user ke input ko bina validate ya encode kiye output mein dikha deti hai.

Ek attacker XSS ka use karke kisi unsuspecting user ko malicious script bhej sakta hai. End user ke browser ko yeh nahi pata hota ki script par bharosa nahi karna chahiye, aur woh JavaScript ko execute kar deta hai. Kyunki browser ko lagta hai ki script kisi trusted source se aayi hai, isliye yeh malicious script aapke browser mein save aur us site ke sath use hone wale kisi bhi cookies, session tokens, ya doosri sensitive information tak access pa sakti hai. Yeh scripts HTML page ke content ko bhi rewrite kar sakti hain.

Kunki yeh ek reflected XSS hai, isliye malicious code remote web application mein stored nahi hota, isiliye iske liye thodi social engineering (jaise email ya chat ke zariye link bhejna) ki zarurat padti hai.



Objective (lakshya)

Jaise-tise karke, logged in user ki cookie chori karein.



Low Level

Low level par requested input ko output text mein use karne se pehle check nahi kiya jata.

Spoiler (jawab): ?name=<script>alert("XSS");</script>.

Medium Level

Developer ne JavaScript ko disable karne ke liye "<script>" ke sabhi references ko hatane ke liye ek simple pattern matching add karne ki koshish ki hai.

Spoiler (jawab): Its cAse sENSiTiVE.

High Level

Developer ko ab lagta hai ki woh "<s*c*r*i*p*t" pattern ko hata kar sabhi JavaScript ko disable kar sakte hain.

Spoiler (jawab): HTML events.

Impossible Level

Inbuilt PHP functions (jaise "htmlspecialchars()") ka use karke, un sabhi values ko escape karna possible hai jo input ke behavior ko badal sakti hain.
