Help - Authorisation Bypass

Parichay (About)

Jab developers ko complex systems mein authorisation matrices banani padti hain, toh unke liye har jagah sahi checks lagana bhool jaana bahut aasan hota hai, khaas kar un jagahon par jo browser ke zariye directly accessible nahi hoti hain, jaise ki API calls.

Ek tester ke taur par, aapko system ki har ek call ko dekhna chahiye aur phir alag-alag levels ke users ke saath usko test karna chahiye taaki yeh ensure ho sake ki checks properly ho rahe hain. Yeh aksar ek lamba aur boring task ho sakta hai, especially jab ek bada matrix ho jismein bahut saare alag-alag user types hon, lekin yeh testing karna critical hai kyunki ek bhi chhoota hua check kisi attacker ko confidential data ya functions tak access dilwa sakta hai.



Objective (lakshya)

Aapka goal is user management system ko sabhi chaaron security levels par test karna hai taaki un areas ko identify kiya ja sake jahan authorisation checks miss ho gaye hain.

Yeh system sirf admin user ke access ke liye design kiya gaya hai, toh admin ke taur par login karke ki gayi sabhi calls ko dekhein, aur phir alag user ke taur par login karke unhe reproduce karne ki koshish karein.

Agar aapko doosre user ki zaroorat hai, toh aap gordonb / abc123 use kar sakte hain.


Low Level

Non-admin users ke paas 'Authorisation Bypass' menu option nahi hota hai.

Spoiler (jawab): Try browsing directly to /vulnerabilities/authbypass/.


Medium Level

Developer ne page ke HTML ka access lock down kar diya hai, lekin yeh check karein ki jab admin ke taur par login karte hain toh page kaise populate hota hai.

Spoiler (jawab): Try browsing directly to /vulnerabilities/authbypass/get_user_data.php to access the API which returns the user data for the page.


High Level

HTML page aur data retrieve karne wali API dono ko lock down kar diya gaya hai, lekin data update karne ka kya? Aapko ensure karna hoga ki aap site ki har call ko test karein.

Spoiler (jawab): GET calls to retrieve data have been locked down but the POST to update the data has been missed, can you figure out how to call it?

Spoiler (jawab): This is one way to do it:

fetch('change_user_details.php', {
method: 'POST',
headers: {
'Accept': 'application/json',
'Content-Type': 'application/json'
},
body: JSON.stringify({ 'id':1, "first_name": "Harry", "surname": "Hacker" })
}
)
.then((response) => response.json())
.then((data) => console.log(data));

Impossible Level

Umeed hai ki is level par sabhi functions data tak access dene se pehle authorisation ko properly check karte hain.

Halaanki page par kuch non-authorisation related issues ho sakti hain, toh isko poori tarah secure maan kar ignore na karein.
