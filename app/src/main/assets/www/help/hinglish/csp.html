Help - Content Security Policy (CSP) Bypass

Parichay (About)

Content Security Policy (CSP) ka use yeh define karne ke liye hota hai ki scripts aur doosre resources kahan se load ya execute ho sakte hain. Yeh module aapko developers ki common mistakes ki wajah se policy ko bypass karne ke tareeqon ke baare mein batayega.

Inmein se koi bhi vulnerability CSP mein khud ki actual vulnerability nahi hai, yeh unke implementation ke tareeqe mein vulnerabilities hain.



Objective (lakshya)

Content Security Policy (CSP) ko bypass karein aur page mein JavaScript execute karein.



Low Level

Policy ko examine karein aur saare aise sources find karein jinhe external script files host karne ke liye use kiya ja sake.

Yeh exercise originally Pastebin ke sath kaam karne ke liye likhi gayi thi, fir Hastebin ke liye update ki gayi, fir Toptal ke liye, lekin yeh sabhi kaam karna band kar chuke hain kyunki yeh aise alag-alag headers set karte hain jo browser ko download hone ke baad JavaScript execute karne se rokte hain. Tab se do nayi services identify ki gayi hain: UNPKG aur jsDelivr. Pehli wali NPM packages ke liye proxy hai, aur doosri GitHub files ke liye. Dono ko isliye design kiya gaya hai ki kisi bhi file tak raw access mil sake aur yeh koi bhi aise headers set nahi karti jo injection ko rokein.

Maine apni site par kuch aisi files bhi rakhi hain jo yeh demonstrate karne mein help karti hain ki kaise alag-alag headers aur file extensions execution ko block kar sakte hain.

Spoiler (jawab): 
https://cdn.jsdelivr.net/gh/digininja/csp_bypass/alert.js - Using jsDelivr to server a JavaScript file stored on GitHub.
https://unpkg.com/@digininja/csp_bypass@1.0.0/index.js - Using UNPKG to access a JavaScript file in an NPM package.
https://digi.ninja/dvwa/alert.js - Will work, this is a normal JavaScript file served with the correct headers.
https://digi.ninja/dvwa/alert.txt - This will not work as it has the wrong content type set by the web server due to its file extension.
https://digi.ninja/dvwa/cookie.js - This will work and will show your cookies
https://digi.ninja/dvwa/forced_download.js - As the name says, the server sets the "Content-Disposition: attachment" header for this to force the browser to download it rather than execute it.
https://digi.ninja/dvwa/wrong_content_type.js - This will not work as the web server ignores the file extension and forces the content type to get set as "plain/text" which prevents the browser executing it.

Medium Level

CSP policy attackers dwara inline scripts add kiye jaane se rokne ke liye ek nonce ka use karne ki koshish karti hai.

Spoiler (jawab): Examine the nonce and see how it varies (or doesn't).

High Level

Page source/jsonp.php par ek JSONP call karta hai jisme callback ke liye function ka naam pass kiya jata hai, aapko callback function change karne ke liye jsonp.php script ko modify karna hoga.

Spoiler (jawab): The JavaScript on the page will execute whatever is returned by the page, changing this to your own code will execute that instead

Impossible Level

Yeh level high level ka ek update hai jisme JSONP call ka callback function hardcoded hota hai aur CSP policy sirf external scripts allow karne ke liye locked down hoti hai.
