Help - Insecure CAPTCHA

Parichay (About)

Ek CAPTCHA ek aisa program hota hai jo yeh pehchan sakta hai ki user ek insaan hai ya computer. Aapne inko dekha hi hoga - web registration forms ke niche colourful images jinme distorded text hota hai. CAPTCHAs ka use bahut saari websites "bots" yaani automated programs jo spam generate karne ke liye likhe jaate hain, unke abuse ko rokne ke liye karti hain. Koi bhi computer program distorted text ko utna acchi tarah nahi padh sakta jitna insaan padh sakte hain, isliye bots CAPTCHAs se protected sites ko navigate nahi kar paate.

CAPTCHAs ka use aksar sensitive functionality ko automated bots se bachane ke liye kiya jata hai. Aisi functionality me aamtaur par user registration aur changes, password changes, aur content post karna shamil hota hai. Is example me, CAPTCHA user account ki password change karne ki functionality ko guard kar raha hai. Yeh CSRF attacks ke sath-sath automated bot guessing se bhi limited protection deta hai.



Objective (lakshya)

Aapka aim hai, kharab CAPTCHA system ki wajah se current user ka password automated tarike se change karna.



Low Level

Is CAPTCHA ke sath problem yeh hai ki yeh easily bypass ho jata hai. Developer ne yeh assumption banaya hai ki saare users screen 1 se jayenge, CAPTCHA complete karenge, aur phir agli screen par move karenge jahan actually password update hota hai. Naye password ko seedhe change page par submit karke, user CAPTCHA system ko bypass kar sakta hai.

Low security me is challenge ko complete karne ke liye jo parameters chahiye honge woh kuch is tarah honge:

Spoiler (jawab): ?step=2&password_new=password&password_conf=password&Change=Change.

Medium Level

Developer ne session ke around state rakhne aur yeh track karne ki koshish ki hai ki user ne data submit karne se pehle successfully CAPTCHA complete kiya tha ya nahi. Kyunki state variable (Spoiler (jawab): passed_captcha) client side par hai, isliye ise attacker dwara kuch is tarah manipulate kiya ja sakta hai:

Spoiler (jawab): ?step=2&password_new=password&password_conf=password&passed_captcha=true&Change=Change.

High Level

Yahan development code chhoot gaya hai, jise production me kabhi remove nahi kiya gaya tha. CAPTCHA field me invalid values allow karne ke liye development values ko mimic karna possible hai.

Check ko skip karne ke liye aapko apna user-agent (Spoiler (jawab): reCAPTCHA) spoof karna padega aur sath hi CAPTCHA value (Spoiler (jawab): hidd3n_valu3) ka use karna padega.


Impossible Level

Impossible level me, developer ne attack ke saare raaste band kar diye hain. Process ko simplify kar diya gaya hai taaki data aur CAPTCHA verification ek hi single step me ho jaye. Alternately, developer state variable ko server side par bhi move kar sakta tha (medium level ki tarah), jisse user ise change na kar sake.
