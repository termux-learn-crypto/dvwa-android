Help - Cross Site Scripting (Stored)

"Cross-Site Scripting (XSS)" attacks ek tarah ki injection problem hain, jismein malicious scripts ko normally safe aur trusted websites ke andar inject kar diya jata hai. XSS attacks tab hote hain jab ek attacker web application ka use karke koi malicious code, jo zyadatar browser side script ke form mein hota hai, kisi doosre end user ko bhejta hai. Yeh flaws jo in attacks ko successful hone dete hain, kaafi widespread hain aur wahan aate hain jahan web application user se aaye input ko output mein bina validate ya encode kiye use kar leta hai.

Ek attacker XSS ka use karke kisi unsuspecting user ko malicious script bhej sakta hai. End user ke browser ko yeh nahi pata hota ki script par bharosa nahi karna chahiye, aur woh us JavaScript ko execute kar deta hai. Kyunki use lagta hai ki script kisi trusted source se aayi hai, isliye woh malicious script aapke browser mein stored kisi bhi cookies, session tokens, ya doosri sensitive information ko access kar sakti hai jo us site ke sath use hoti hai. Yeh scripts HTML page ke content ko bhi rewrite kar sakti hain.

Yeh XSS database ke andar stored hota hai. XSS tab tak permanent rehta hai jab tak database reset na ho jaye ya payload ko manually delete na kar diya jaye.



Objective (lakshya)

Sabhi users ko apni pasand ki kisi web page par redirect karein.



Low Level

Low level mein requested input ko output text mein include karne se pehle bilkul check nahi kiya jata.

Spoiler (jawab): Either name or message field: <script>alert("XSS");</script>.

Medium Level

Developer ne thodi protection add ki hai, lekin sabhi fields par same tarike se implementation nahi kiya hai.

Spoiler (jawab): name field: <sCriPt>alert("XSS");</sCriPt>.

High Level

Developer ko lagta hai ki unhone "<s*c*r*i*p*t" pattern ko remove karke sabhi scripts ka use disable kar diya hai.

Spoiler (jawab): HTML events.

Impossible Level

Inbuilt PHP functions (jaise ki "htmlspecialchars()") ka use karke, un sabhi values ko escape karna possible hai jo input ke behaviour ko change kar sakti hain.
