Help - File Upload

Parichay (About)

Uploaded files web applications ke liye kaafi bada risk represent karte hain. Bahut saare attacks ka pehla step ye hota hai ki target system par kuch code pahunchaya jaaye. Fir attacker ko bas aisa tareeqa dhoondhna hota hai jisse wo code execute ho jaaye. File upload ka use karke attacker apna pehla step aasaani se complete kar leta hai.

Unrestricted file upload ke consequences kuch bhi ho sakte hain, jaise poore system ka takeover, file system overload ho jana, backend systems par attacks forward karna, aur simple defacement. Ye is baat par depend karta hai ki application uploaded file ke sath kya karta hai, aur use kahan store kiya jata hai.



Objective (lakshya)

Is file upload vulnerability ka use karke target system par apni marzi ka koi bhi PHP function execute karein (jaise phpinfo() ya system()).



Low Level

Low level mein upload kiye ja rahe file ke contents ko kisi bhi tarah se check nahi kiya jata. Ye sirf trust par kaam karta hai.

Spoiler (jawab): Upload any valid PHP file with command in it.

Medium Level

Medium level use karte waqt, ye upload hone ke time client ki taraf se bhejhe gaye reported file type ko check karta hai.

Spoiler (jawab): Worth looking for any restrictions within any "hidden" form fields.

High Level

Jaise hi client se file receive ho jaati hai, server request mein included kisi bhi image ko resize karne ki koshish karta hai.

Spoiler (jawab): need to link in another vulnerability, such as file inclusion.

Impossible Level

Ye abhi tak ke sabhi levels ki cheezein check karega, aur sath hi image ko re-encode bhi karega. Isse ek nayi image banegi, jisse saara "non-image" code (metadata samet) hat jayega.

Reference: https://owasp.org/www-community/vulnerabilities/Unrestricted_File_Upload
