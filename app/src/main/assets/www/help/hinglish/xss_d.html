Help - Cross Site Scripting (DOM Based)

Parichay (About)

"Cross-Site Scripting (XSS)" attacks ek tarah ki injection problem hain, jisme malicious scripts ko un websites mein inject kar diya jata hai jo otherwise safe aur trusted hoti hain. XSS attacks tab hote hain jab ek attacker web application ka use karke malicious code (aam taur par browser side script ki form mein) kisi doosre end user ko bhejta hai. Aise flaws kaafi common hain aur wahan milte hain jahan web application user se aaye input ko bina validate ya encode kiye output mein dikha deti hai.

Ek attacker XSS ka use karke kisi unsuspecting user ko malicious script bhej sakta hai. End user ke browser ko yeh nahi pata hota ki script par bharosa nahi karna chahiye, aur woh JavaScript ko execute kar deta hai. Kyunki browser ko lagta hai ki script kisi trusted source se aayi hai, isliye woh malicious script aapke browser mein stored kisi bhi cookies, session tokens, ya doosri sensitive information ko access kar sakti hai jo us site ke sath use ho rahi ho. Yeh scripts HTML page ke content ko bhi rewrite kar sakti hain.

DOM Based XSS, reflected XSS ka hi ek special case hai jisme JavaScript URL ke andar chhupi hoti hai aur jab page render ho raha hota hai tab page ki JavaScript hi usko fetch karti hai, na ki page serve hote waqt usmein embedded hoti hai. Is wajah se yeh doosre attacks se zyada stealthy ho sakta hai aur WAFs ya doosri protections jo page body ko read karti hain, unhein koi bhi malicious content nahi dikhta.

Objective (lakshya)

Kisi doosre user ke browser mein apni khud ki JavaScript run karein, aur iska use karke logged-in user ki cookie chori karein.
