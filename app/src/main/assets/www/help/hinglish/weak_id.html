Help - Weak Session IDs

Parichay (About)

Ek user ke login karne ke baad, site par kisi specific user ki tarah access pane ke liye aksar sirf session ID ki hi zarurat padti hai. Agar woh session ID calculate ki ja sake ya aasani se guess ho sake, toh attacker ke liye user accounts ka access pana bahut aasan ho jata hai, bina passwords par brute force attack kiye ya Cross-Site Scripting jaisi doosri vulnerabilities dhunde.

Objective (lakshya)

Yeh module dvwaSession cookie value set karne ke char alag-alag tareeqe use karta hai, har level ka objective yeh pata lagana hai ki ID kaise generate hoti hai aur phir doosre system users ki IDs ka andaza lagana hai.

Low Level

Cookie ki value bilkul saaf taur par predictable honi chahiye.

Medium Level

Value low level ke muqable thodi zyada random lagti hai par agar aap kuch values collect karein toh aapko ek pattern dikhne lagega.

High Level

Pehle yeh pata lagayein ki value kis format mein hai aur phir yeh samajhne ki koshish karein ki values generate karne ke liye input mein kya use ho raha hai.

Cookie mein extra flags bhi add kiye ja rahe hain, isse challenge par koi asar nahi padta lekin yeh un extra protections ko highlight karta hai jo cookies ko protect karne ke liye add ki ja sakti hain.

Impossible Level

Is level par cookie value predictable nahi honi chahiye lekin aap try karne ke liye azaad hain.

Extra flags ke sath-sath, cookie ko challenge ke domain aur path ke sath bhi tie kiya ja raha hai.
