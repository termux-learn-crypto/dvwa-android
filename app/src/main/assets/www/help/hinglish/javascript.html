Help - Client Side JavaScript

Parichay (About)

Is section ke attacks aapko yeh sikhane ke liye banaye gaye hain ki browser mein JavaScript ka kaise use hota hai aur isko kaise manipulate kiya ja sakta hai. Yeh attacks sirf network traffic analyze karke bhi kiye ja sakte hain, par woh point nahi hai aur shayad kaafi mushkil bhi hoga.

Objective (lakshya)

Level jeetne ke liye bas "success" phrase submit karein. Obviously, yeh itna aasaan nahi hai, har level mein alag-alag protection mechanisms implement kiye gaye hain, pages mein di gayi JavaScript ko analyze karke protections ko bypass karne ke liye manipulate karna padta hai.

Low Level

Saari JavaScript page ke andar hi included hai. Source code padhein aur pata lagayein ki phrase ke sath match hone wala token generate karne ke liye kaun sa function use ho raha hai, aur phir us function ko manually call karein.

Spoiler (jawab): Change the phrase to success and then use the function generate_token() to update the token.


Medium Level

JavaScript ko alag file mein extract karke minify kar diya gaya hai. Aapko included file ka source view karke yeh samajhna hoga ki yeh kya kar rahi hai. Firefox aur Chrome dono mein Pretty Print feature hota hai jo compression ko reverse karke code ko readable format mein display karne ki koshish karta hai. 

Spoiler (jawab): The file uses the setTimeout function to run the do_elsesomething function which generates the token.


High Level

JavaScript ko kam se kam ek engine ke through obfuscate kiya gaya hai. Aapko code ke through ek-ek step chal kar yeh pata lagana hoga ki kya cheez useful hai, kya garbage hai, aur mission complete karne ke liye kis cheez ki zaroorat hai. 

Spoiler (jawab): If it helps, two packers have been used, the first is from Dan's Tools and the second is the JavaScript Obfuscator Tool.
Spoiler 2: This deobfuscation tool seems to work the best on this code deobfuscate javascript.
Spoiler 3: This is one way to do it... run the obfuscated JS through a deobfuscation app, intercept the response for the obfuscated JS and swap in the readable version. Work out the flow and you will see three functions that need to be called in order. Call the functions at the right time with the right parameters.


Impossible Level

Aap kabhi bhi user par trust nahi kar sakte aur yeh maan ke chalna padta hai ki user ko bheja gaya koi bhi code manipulate ya bypass kiya ja sakta hai, isliye yahan koi Impossible level nahi hai.
