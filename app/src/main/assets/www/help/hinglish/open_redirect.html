Help - Open HTTP Redirect

Parichay (About)

OWASP isko aise define karta hai:

Unvalidated redirects and forwards are possible when a web application accepts untrusted input that could cause the web application to redirect the request to a URL contained within untrusted input. By modifying untrusted URL input to a malicious site, an attacker may successfully launch a phishing scam and steal user credentials.

Jaise ki upar bataya gaya hai, iska ek common use yeh hai ki ek aisa URL banaya jaye jo shuru mein real site par jaye lekin phir victim ko kisi attacker ke control wali site par redirect kar de. Yeh site target ki login page ki clone ho sakti hai credentials steal karne ke liye, target site par kisi service ke liye credit card details mangne ke liye, ya fir simply ads se bhari hui ek spam page ho sakti hai.



Objective (lakshya)

Redirect page ka galat use karke user ko DVWA site se bahar ya fir site par kisi doosre page par le jayein jo expect nahi kiya gaya tha.



Low Level

Redirect page par koi limitations nahi hain, aap jahan chahein wahan redirect kar sakte hain.

Spoiler (jawab): Try browsing to /vulnerabilities/open_redirect/source/low.php?redirect=https://digi.ninja


Medium Level

Code aapko absolute URLs use karne se rokta hai jo user ko site se bahar le jayein, isliye aap ya toh relative URLs use kar sakte hain unhe same site ke doosre pages par le jaane ke liye ya fir ek Protocol-relative URL.

Spoiler (jawab): Try browsing to /vulnerabilities/open_redirect/source/low.php?redirect=//digi.ninja


High Level

Redirect page yeh koshish karta hai ki aapko sirf info.php page par hi redirect karne ke liye lock kiya jaye, lekin yeh yeh check karke kiya jata hai ki URL mein "info.php" aata hai ya nahi.

Spoiler (jawab): Try browsing to /vulnerabilities/open_redirect/source/low.php?redirect=https://digi.ninja/?a=info.php


Impossible Level

Redirect target ke roop mein koi page ya URL accept karne ke bajaye, system ID values ka use karta hai redirect page ko yeh batane ke liye ki kahan redirect karna hai. Yeh system ko sirf unhi pages par redirect karne ke liye baandh deta hai jinke baare mein yeh jaanta hai, isliye attacker ke liye cheezon ko modify karke apni pasand ke kisi page par le jaane ka koi tareeqa nahi rehta.
