Help - Command Injection

Parichay (About)

Command injection attack ka main maqsad vulnerable application mein attacker dwara specify kiye gaye commands ko inject aur execute karna hota hai. Aise situations mein, jo application unwanted system commands execute karti hai, woh ek pseudo system shell ki tarah kaam karti hai, aur attacker ise kisi bhi authorized system user ki tarah use kar sakta hai. Halanki, commands wahi privileges aur environment ke sath execute hote hain jo web service ke paas hote hain.

Command injection attacks zyadatar cases mein input data ki sahi validation na hone ki wajah se possible hote hain, jise attacker manipulate kar sakta hai (forms, cookies, HTTP headers etc.).

Operating Systems (OS) jaise ki Linux aur Windows mein syntax aur commands alag-alag ho sakte hain, jo ki unke desired actions par depend karta hai.

Is attack ko "Remote Command Execution (RCE)" bhi kaha ja sakta hai.



Objective (lakshya)

RCE ke through remotely pata lagayein ki OS par web service ka user kaun hai, aur machine ka hostname kya hai.



Low Level

Isme kai PHP functions mein se kisi ek mein direct input diya ja sakta hai jo OS par commands execute karenge. Designed command se escape karke unintentional actions execute karna possible hai.

Yeh request mein ye jod kar kiya ja sakta hai, "ek baar command successfully execute ho jaye, toh yeh command run karo". 

Spoiler (jawab): To add a command "&&". Example: 127.0.0.1 && dir.

Medium Level

Developer ne command injection ki kuch problems ke baare mein padha hai, aur input ko filter karne ke liye alag-alag pattern patching lagayi hai. Halanki, yeh kaafi nahi hai.

Desired command se bahar nikalne ke liye aur bhi alag-alag system syntaxes ka use kiya ja sakta hai.

Spoiler (jawab): e.g. background the ping command.

High Level

High level mein, developer wapas drawing board par jata hai aur aur bhi zyada patterns match karne ke liye dalta hai. Lekin yeh bhi kaafi nahi hai.

Developer ne filters mein shayad thodi si typo kar di hai aur use lagta hai ki ek specific PHP command use is galti se bacha legi.

Spoiler (jawab): trim()
			removes all leading & trailing spaces, right?.

Impossible Level

Impossible level mein, challenge ko phir se likha gaya hai, taaki sirf ek bohot hi strict input allow ho. Agar yeh match nahi karta aur ek specific result nahi deta, toh ise execute nahi hone diya jayega. "Black listing" filtering (koi bhi input allow karna aur unwanted ko hatana) ke bajaye, yeh "white listing" use karta hai (sirf kuch specific values allow karna).
